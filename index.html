Step 2: Db2 AI for z/OS Tuning Recommendation

AI-driven access path evaluation surfaces an index covering recommendation to eliminate table I/O.

Tuning Insight #IDX-2026-8814: Index Extension Recommendation

Confidence Level: 96% | Projected Cost Reduction: -91.5%

✨ AI Optimization Ready

CURRENT ACCESS PATH

IX_TXN_ACCT_DT (ACCT_ID, TXN_DATE)

  • MATCHCOLS = 1 (ACCT_ID exact match)
  • INDEXONLY = 'N' (Must fetch every row from data page)
  • Result: 2.48M buffer pool getpages per batch run

RECOMMENDED ACCESS PATH (COVERING INDEX)

IX_TXN_ACCT_EOD (ACCT_ID, TXN_DATE, STATUS_CODE, TXN_AMOUNT)

  • MATCHCOLS = 2 (Exact on ACCT_ID, Range on TXN_DATE)
  • INDEXONLY = 'Y' (100% satisfied from index b-tree)
  • Result: Zero synchronous table data page reads

Recommended DDL:

CREATE INDEX BANKDB01.IX_TXN_ACCT_EOD ON BANKDB01.ACCT_TRANSACTION ( ACCT_ID ASC, TXN_DATE ASC, STATUS_CODE ASC, TXN_AMOUNT ASC ) USING STOGROUP BANKSTG PRIQTY 150000 SECQTY 15000 BUFFERPOOL BP2 CLOSE NO; COMMIT;
